## 1. Ringkasan Eksekutif & Kekangan Seni Bina Mandatori

Berdasarkan semakan mendalam terhadap sumber-sumber autoritatif di atas, pembangunan ABANGCOLEK v2.4 beroperasi di bawah prinsip **"Rules Own The Money"** dan **"Sifar Kos Awan Baharu" (Zero-New-Paid-Cloud-Spend)**.

### Kekangan Utama (Hard Architectural Constraints):
1. **Stack & Runtime Aplikasi:**
   - Satu aplikasi Modular Monolith: React 19 / Vite + Bun runtime.
   - Pindaan seni bina ke Next.js, Hono, atau framework luar adalah **dilarang sama sekali** (ADR-0003 §10).
2. **Autoriti Transaksi & Pangkalan Data:**
   - Autoriti komersial tempatan adalah SQLite (`PlatformStore`). Autoriti awan adalah Supabase CAS whole-snapshot.
   - Perkhidmatan AI/Copilot dilarang membuka fail pangkalan data transaksi secara langsung atau bertindak sebagai lejar kewangan.
3. **Protokol CopilotKit & Google ADK:**
   - Runtime rasmi CopilotKit TypeScript Fetch handler `/v2` (`/api/platform/copilot/v2` atau `/api/copilotkit`) beroperasi pada port `3020`.
   - Penyambung `HttpAgent` menyambungkan runtime ke perkhidmatan Python Google ADK (`agents/google-adk/`) pada port `8030`.
   - Bind loopback tempatan: UI `3000`, API Kanonikal `3010`, Copilot Runtime `3020`, ADK `8030`.
4. **Hierarki Model Percuma (Strict Free-Only Sequence):**
   - Tiada sebarang model komersial/berbayar dibenarkan.
   - Urutan wajib: `gemini-3.6-flash` (Primary Free) -> `gemini-3.5-flash-lite` (Secondary Free) -> `nvidia/nemotron-3-super-120b-a12b:free` (OpenRouter Free).
   - Adapter OpenRouter dibina sebagai subkelas `BaseLlm` (`agents/google-adk/models/free_openrouter.py`) menggunakan `httpx@0.28.1`, bukan LiteLLM.
5. **Had Bajet Operasi Sesi Interaktif:**
   - Had masa (interactive deadline): 30 saat per run.
   - Had alatan (tool dispatches): Maksimum 6 alatan per run (termasuk discovery, pagination, retry, dan delegation).
   - Had panggilan model: Maksimum 3 panggilan per run (termasuk parent, specialist, dan failover).
   - Token per call: Maksimum 8,192 input / 1,024 output. Kumulatif run: 24,576 input / 3,072 output.
   - Sub-agent delegation: Kedalaman 1 (depth 1), konkurensi 2, maksimum 3 panggilan specialist.
6. **Integriti Kewangan (Rules Own The Money):**
   - Semua nilai kewangan menggunakan integer sen (RM 1.00 = 100 sen). Polisi margin menggunakan integer basis points (Bps, 1% = 100 bps).
   - Penilaian margin (FIN-01): `contributionSen * 10000 >= netSalesSen * minimumMarginBps` menggunakan aritmetik tepat BigInt. Pembundaran paparan (display rounding) tidak boleh meluluskan nisbah margin.
   - Agihan baki integer (allocation): Kaedah Largest Remainder dengan pemecah seri (tie-break) ID barisan yang stabil.
7. **Kitaran Hayat Human-In-The-Loop (HITL / CPK-06):**
   - Semakan tarikh luput (`expiry`) mandatori sebelum sebarang mutasi.
   - Kelulusan pengasas **BUKAN** pelaksanaan: `executionReceipt: undefined`.
   - Status diluluskan mestilah melabelkan `executionBlockedReason: 'EXECUTOR_UNAVAILABLE'` sehingga executor fizikal kanonikal disahkan wujud dan berjaya commit.

## 4. Analisis Kategori & Hubungan Antara Fasa

1. **Fasa 03A mendahului Fasa 01:**
   - Integriti kewangan dan peraturan keselamatan ("Rules Own The Money") mesti diuji dan disahkan hijau sebelum struktur fail dipindahkan. Ini mengelakkan kekeliruan antara regresi logik bisnes dengan ralat import fail.
2. **Fasa 01 menyediakan destinasi Fasa 03B:**
   - Restrukturisasi Fasa 01 membina folder `server/modules/`, `server/application/`, dan `server/agents/tools/`.
   - 32 Alatan Lanjutan dalam Fasa 03B dibina terus pada folder destinasi ini, bukan pada laluan legasi `server/platform/`.
3. **Fasa 02 membina jambatan untuk Fasa 04:**
   - Runtime TypeScript CopilotKit dan bridge Python Google ADK menyediakan saluran protokol komunikasi AG-UI stream.
   - Fasa 04 (Generative UI) bergantung sepenuhnya kepada saluran ini untuk merender kad visual kanonikal dan menguruskan kitaran hidup alatan.
