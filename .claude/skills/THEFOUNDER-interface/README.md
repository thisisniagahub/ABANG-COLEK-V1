# THEFOUNDER-interface

> Rebuilds the product's UI design system as tokens: colour roles, type scale, spacing and component specs, measured from the original's screenshots and rebuilt with your own assets. Owns product interface craft only - business naming, logo and voice belong to THEFOUNDER-identity. Use when the user says "rebuild the design system", "extract the design tokens", "match the look", "make the UI ours".

## Trigger phrases

- `rebuild the design system`
- `extract the design tokens`
- `match the look`
- `make the UI ours`

## Apa yang skill ini tidak buat (the fence)

- Never designs a name, logo or voice - THEFOUNDER-identity owns business identity.
- Never invents brand colours without measuring the original or asking the user.

## Fail dalam skill ini

contrast.py, SKILL.md, tokens.json
