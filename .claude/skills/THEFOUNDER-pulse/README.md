# THEFOUNDER-pulse

> Reads what the original app's real users hate: collects reviews from public sources into a linked dataset, ranks the complaints with counts and linked quotes, and turns them into fixes for the build plus a positioning angle. Nothing is invented - every claim carries its source. Not simulated buyers - THEFOUNDER-crowd; not the market map - THEFOUNDER-battlefield. Use when the user says "what do users hate about X", "read the reviews", "find the angle", "what should we fix first".

## Trigger phrases

- `what do users hate about X`
- `read the reviews`
- `find the angle`
- `what should we fix first`

## Apa yang skill ini tidak buat (the fence)

- Never invents a review, quote or number; every claim carries its source link and the sample size is stated.
- Simulated buyer reactions belong to THEFOUNDER-crowd; competitor maps belong to THEFOUNDER-battlefield.

## Fail dalam skill ini

reviews.py, SKILL.md, themes.json
