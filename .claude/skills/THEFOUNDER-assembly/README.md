# THEFOUNDER-assembly

> The orchestrator of the founder pack. Knows the whole chain - judge the idea, learn the truth, secure the money, build the identity, build the product, go to market, open, operate, measure, grow - finds where the user stands right now, and hands off to the exact next skill with the right inputs. Also runs the chain end to end for users who want to be driven. Use when the user says "run the founder pack", "what should I do next", "where am I in the process", "orchestrate the pack", "start to finish", or when it is unclear which skill owns the current problem.

## Trigger phrases

- `run the founder pack`
- `what should I do next`
- `where am I in the process`
- `orchestrate the pack`
- `start to finish`

## Apa yang skill ini tidak buat (the fence)

- Never skips a stage silently; jumping is allowed only when the user says so
  explicitly, and the skipped stage is named in the handoff.
- Never runs two sibling skills' work itself - it hands off, it does not
  imitate.
- Never declares a stage complete because the user is impatient; the output
  files decide.
