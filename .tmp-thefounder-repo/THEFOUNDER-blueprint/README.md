# THEFOUNDER-blueprint

> Plans the technical build for the app THEFOUNDER-xray mapped: stack choice, database schema, API surface and build order. Technology planning only - it never writes the application code itself. Use when the user says "pick a stack", "design the schema", "plan the API", "what do we build first", or right after the xray map is done.

## Trigger phrases

- `pick a stack`
- `design the schema`
- `plan the API`
- `what do we build first`

## Apa yang skill ini tidak buat (the fence)

- Never plans a build for a business idea that has not survived THEFOUNDER-council.
- Never writes application code - THEFOUNDER-rebuild owns that.

## Fail dalam skill ini

architecture.md, SKILL.md
