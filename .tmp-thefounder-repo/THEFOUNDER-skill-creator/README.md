# THEFOUNDER-skill-creator

> The house standard for creating, reviewing and extending THEFOUNDER-branded skills. Enforces the naming, frontmatter, output-folder, anti-clash and efficiency rules every new skill in the founder pack must follow, and gates a new skill before it is installed. Use when the user says "create a new THEFOUNDER skill", "make a skill for X", "add a skill to the founder pack", "skill guideline", "review my new skill", or wants to extend THEFOUNDER with a new capability.

## Trigger phrases

- `create a new THEFOUNDER skill`
- `make a skill for X`
- `add a skill to the founder pack`
- `skill guideline`
- `review my new skill`
