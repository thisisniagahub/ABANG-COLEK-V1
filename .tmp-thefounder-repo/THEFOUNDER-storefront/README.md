# THEFOUNDER-storefront

> Writes the public face of the finished build: landing page copy around the positioning angle, the pricing page copy, and a linted app-store listing within platform limits. The dated launch plan and opening-day run sheet belong to THEFOUNDER-opening. Use when the user says "write the landing page", "store listing", "pricing page copy", "the public page".

## Trigger phrases

- `write the landing page`
- `store listing`
- `pricing page copy`
- `the public page`

## Apa yang skill ini tidak buat (the fence)

- Never sets the price numbers - THEFOUNDER-pricetag owns pricing strategy.
- Never writes launch dates or run sheets - THEFOUNDER-opening owns those.

## Fail dalam skill ini

listing.example.json, listing.py, SKILL.md
